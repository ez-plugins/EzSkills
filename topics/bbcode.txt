[B][SIZE=6]Skill progression for any plugin[/SIZE]

EzSkills[/B] is a compact RPG progression plugin that layers levelling, XP gain, and timed abilities on top of your server's gameplay. Use it standalone or integrate with plugins like [URL='https://www.spigotmc.org/resources/1-7-1-21-%E2%9A%A1-eztree%E2%9A%A1replant-break-skill-mcmmo-farm-zones.117223/']EzTree[/URL], [URL='https://www.spigotmc.org/resources/ezmine-rank-based-mining-perks-auto-smelt-custom-tools-for-minecraft.131060/']EzMine[/URL], or your own custom plugins to turn repetitive actions into a rewarding skill loop. EzSkills provides a flexible API for adding new abilities, reacting to level-ups, and controlling how much XP any third-party plugin may award.

[B][SIZE=5]Features[/SIZE][/B]

[B]Five built-in skills[/B]
[LIST]
[*][B]Woodcutting[/B] - award XP for felling trees.
[*][B]Mining[/B] - award XP for breaking ores and stone.
[*][B]Fishing[/B] - award XP for catching fish.
[*][B]Fighting[/B] - award XP for combat with mobs and players.
[*][B]Acrobatics[/B] - award XP for jumping, falling, and sprinting.
[/LIST]
Every source plugin that calls [ICODE]EzSkillsAPI.addExperience(plugin, ...)[/ICODE] is subject to the per-plugin XP multiplier and enabled flag you configure centrally - no changes needed in third-party plugins.

[B]Timed abilities[/B]
[LIST]
[*][B]Tree Feller[/B]: The built-in ability for Woodcutting. Players prepare, trigger and ride out an auto-expiring TREE_FELLER window.
[*][B]Custom abilities[/B] (new in 2.0): Any plugin can register its own ability via [ICODE]EzSkillsAPI.registerAbility(definition)[/ICODE]. Custom abilities appear in the [ICODE]/abilities[/ICODE] GUI automatically.
[*][B]Ability state GUI[/B] (new in 2.0): The [ICODE]/abilities[/ICODE] command opens an overview showing every registered ability with its current state - Ready (green), Preparing (yellow), or Active (gold).
[/LIST]

[B]Progression controls[/B]
[LIST]
[*][B]Scaling XP curve[/B]: Tune [ICODE]xp-base[/ICODE] and [ICODE]xp-multiplier[/ICODE] per skill in [ICODE]skills.yml[/ICODE] to keep early levels snappy and late-game grindy.
[*][B]Per-plugin overrides[/B] (new in 2.0): In [ICODE]config.yml[/ICODE] set an [ICODE]xp-multiplier[/ICODE] or [ICODE]enabled: false[/ICODE] for any third-party plugin and any skill - no code changes needed on their side.
[/LIST]

[B]Storage[/B]
[LIST]
[*][B]YAML[/B] - zero-setup flat file, great for small servers.
[*][B]MySQL[/B] - recommended for production; enables leaderboards via [ICODE]/ezskills top[/ICODE].
[/LIST]


[B][SIZE=5]Core gameplay loop[/SIZE][/B]
[LIST=1]
[*][B]Configure[/B] XP curves in [ICODE]skills.yml[/ICODE] and ability timings in [ICODE]abilities.yml[/ICODE].
[*][B]Earn XP[/B] as players break blocks, fish, fight - any event your integration plugin reports.
[*][B]Level up[/B]: [ICODE]SkillLevelUpEvent[/ICODE] fires instantly for rewards, rank unlocks or boss-bar announcements.
[*][B]Prepare and activate[/B] an ability within its warm-up window to use a powerful timed effect.
[*][B]View progress[/B] at any time with [ICODE]/skills[/ICODE] (levels) and [ICODE]/abilities[/ICODE] (ability states).
[/LIST]

[B][SIZE=5]Configuration overview[/SIZE][/B]
[table]
[tr][th]File[/th][th]Controls[/th][/tr]
[tr][td][ICODE]config.yml[/ICODE][/td][td]GUI titles, boss-bar notifications, and [ICODE]plugin-overrides[/ICODE] (per-plugin XP multipliers and enabled flags).[/td][/tr]
[tr][td][ICODE]skills.yml[/ICODE][/td][td]XP base and multiplier per skill (controls the levelling curve).[/td][/tr]
[tr][td][ICODE]abilities.yml[/ICODE][/td][td]Preparation window, active duration, and cooldown per ability.[/td][/tr]
[tr][td][ICODE]storage.yml[/ICODE][/td][td]Storage backend (YAML or MySQL) and connection details.[/td][/tr]
[/table]

[B]Per-plugin XP overrides[/B] (new in 2.0):
[CODE]# config.yml
plugin-overrides:
  MyPlugin:
    woodcutting:
      enabled: true
      xp-multiplier: 1.5   # 50% bonus Woodcutting XP from MyPlugin
    mining:
      enabled: false        # MyPlugin cannot award Mining XP[/CODE]


[B][SIZE=5]API reference[/SIZE][/B]

[B]Skills[/B]
[table]
[tr][th]Method[/th][th]Description[/th][/tr]
[tr][td][ICODE]EzSkillsAPI.addExperience(playerId, skill, amount)[/ICODE][/td][td]Award XP directly with no multiplier applied.[/td][/tr]
[tr][td][ICODE]EzSkillsAPI.addExperience(plugin, playerId, skill, amount)[/ICODE][/td][td]Award XP with the server-configured multiplier and enabled check for your plugin.[/td][/tr]
[tr][td][ICODE]EzSkillsAPI.getSkillLevel(playerId, skill)[/ICODE][/td][td]Return the player's current level.[/td][/tr]
[tr][td][ICODE]EzSkillsAPI.getSkillExperience(playerId, skill)[/ICODE][/td][td]Return the player's accumulated XP.[/td][/tr]
[tr][td][ICODE]EzSkillsAPI.setSkillLevel(playerId, skill, level)[/ICODE][/td][td]Set a level directly, resetting XP to zero.[/td][/tr]
[tr][td][ICODE]EzSkillsAPI.getSkillProfile(playerId)[/ICODE][/td][td]Return the full profile object (null if not cached).[/td][/tr]
[/table]

[B]Custom skills[/B]
[table]
[tr][th]Method[/th][th]Description[/th][/tr]
[tr][td][ICODE]EzSkillsAPI.registerSkill(definition)[/ICODE][/td][td]Register a custom skill at runtime; progress is persisted automatically.[/td][/tr]
[tr][td][ICODE]EzSkillsAPI.getRegisteredSkills()[/ICODE][/td][td]List all registered custom skill definitions.[/td][/tr]
[/table]

[B]Abilities[/B]
[table]
[tr][th]Method[/th][th]Description[/th][/tr]
[tr][td][ICODE]EzSkillsAPI.registerAbility(definition)[/ICODE][/td][td]Register a custom ability; it appears in [ICODE]/abilities[/ICODE] automatically.[/td][/tr]
[tr][td][ICODE]EzSkillsAPI.getRegisteredAbilities()[/ICODE][/td][td]List all registered ability definitions (built-in + custom).[/td][/tr]
[tr][td][ICODE]EzSkillsAPI.prepareAbility(playerId, ability)[/ICODE][/td][td]Enter the preparation (charged) state.[/td][/tr]
[tr][td][ICODE]EzSkillsAPI.activateAbility(playerId, ability)[/ICODE][/td][td]Activate the ability immediately.[/td][/tr]
[tr][td][ICODE]EzSkillsAPI.deactivateAbility(playerId, ability)[/ICODE][/td][td]Cancel or end the ability early.[/td][/tr]
[tr][td][ICODE]EzSkillsAPI.isAbilityActive(playerId, ability)[/ICODE][/td][td]Check whether the ability is currently active.[/td][/tr]
[/table]

[B]Events to listen for[/B]
[LIST]
[*][ICODE]SkillLevelUpEvent[/ICODE] - fired when a player reaches a new level (carries old and new level).
[*][ICODE]EzSkillsAbilityPrepareEvent[/ICODE] - fired when an ability enters its warm-up window.
[*][ICODE]EzSkillsAbilityActivateEvent[/ICODE] - fired when an ability activates.
[*][ICODE]EzSkillsAbilityDeactivateEvent[/ICODE] - fired when an ability ends or is cancelled.
[/LIST]

[B]Implementing a custom ability[/B]
[CODE]public class NightVisionAbility implements AbilityDefinition {
    @Override public String   getName()        { return "NIGHT_VISION"; }
    @Override public String   getDisplayName() { return "Night Vision"; }
    @Override public Material getIcon()        { return Material.ENDER_EYE; } // optional - defaults to NETHER_STAR
    @Override public String   getDescription() { return "See clearly in the dark."; }
    @Override public String   getSkillName()   { return "FIGHTING"; }
}

// In onEnable:
EzSkillsAPI.registerAbility(new NightVisionAbility());[/CODE]
